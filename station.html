How to print without the print window popping up every time

Windows (Chrome or Edge): set your printer as the default printer. Right-click the browser shortcut, choose Properties, and add --kiosk-printing at the end of the Target box, after a space. Close all browser windows, open the browser from that shortcut, then open this page.

Mac (Terminal): open -a "Google Chrome" --args --kiosk-printing after fully quitting Chrome. Set your printer as the default in System Settings → Printers.

Then turn Auto-print on. Each new collage prints by itself. Phones and tablets can't print silently, so tap Print on each photo.

Keep this page open on the laptop, plugged in, and the screen awake. Photos can take 10–60 seconds to show up after a guest taps Done.
